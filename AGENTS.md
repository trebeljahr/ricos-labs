# Agent Instructions

If the operator maintains a machine-level agent file (e.g.
`~/.agents/AGENTS.md` or `~/.claude/CLAUDE.md`), read and follow it
first.

The instructions for this repository are in `CLAUDE.md`. Read that file
before you work here. It holds the commands, the file layout, the
environment rules, the release rules and the code style.

One rule is repeated here, because a mistake cannot be taken back: every
push to `main` is a production release to https://ricoslabs.com. Commit
locally, and push only when the operator asks for a release.
